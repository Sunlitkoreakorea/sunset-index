# 노을 지수 (Sunset Index)

구름 높이·습도·미세먼지 예보로 **오늘부터 2주(14일)간 저녁노을이 얼마나 예쁠지** 0~100점으로 계산하는 정적 웹 계산기입니다.

- 사이트: https://sunlitkoreakorea.github.io/sunset-index/
- 기본 위치: 민족사관고등학교 (강원 횡성, 37.4592°N 128.1436°E)
- **내 위치** 버튼: 휴대폰·노트북 GPS 위치로 계산하고, 다음에 열 때도 내 위치를 다시 잡습니다. **민사고** 버튼으로 언제든 돌아갈 수 있어요.
- 다른 곳을 직접 지정: `?lat=37.5665&lon=126.978&name=서울`

## 노을 지수에 필요한 데이터

| 데이터 | 왜 필요한가 | 쓸 수 있는 곳 | 이 앱 |
|---|---|---|---|
| **층별 구름량** (하층 0–3 km, 중층 3–8 km, 상층 8 km+) | 노을은 높은 구름이 물들어야 진해지고, 낮은 구름은 빛을 막는다. 가장 중요한 자료 | Open-Meteo 예보 API (ECMWF·GFS 등 모델 묶음) · 기상청 API허브 수치모델 KIM/UM 격자 (인증키, 격자 파일) · NOAA GFS / ECMWF Open Data 원자료 (GRIB2) | Open-Meteo |
| **해 지는 방향 수백 km 지점의 구름** | 해가 지평선 아래 1~3°일 때 구름에 닿는 빛은 서쪽 100~350 km를 낮게 지나온다. 거기가 막히면 구름이 있어도 안 물든다 | 위와 같은 모델을 여러 지점에서 조회 | Open-Meteo 다지점 조회 (7곳) |
| 습도·시정 | 습하고 뿌연 날은 색이 흐려진다 | Open-Meteo · 기상청 단기예보 습도(REH) · 기상청 지상관측(ASOS) 시정 | Open-Meteo |
| 강수 | 비가 오면 하늘이 안 보인다 | Open-Meteo · 기상청 단기예보 강수형태(PTY)·강수량(PCP) | Open-Meteo |
| **에어로졸 광학두께(AOD)·미세먼지** | 입자가 조금 있으면 붉은색이 진해지고, 많으면 뿌옇다 | Open-Meteo 대기질 API (Copernicus CAMS 전지구 예보, 약 45 km, 5일) · 에어코리아 측정소 실시간 (공공데이터포털 인증키, 관측만) | Open-Meteo 대기질 |

| (선택) 실시간 위성 구름 | 당일 몇 시간 앞 예보 보정 | 천리안 2A호(GK2A) 국가기상위성센터 · AWS 공개 데이터 | 아직 안 씀 |
| (선택) 지형 고도 | 산에 가려 해가 일찍 지는 효과 (민사고는 산골짜기) | Open-Meteo Elevation API (Copernicus DEM 90 m) | 아직 안 씀 |

**Open-Meteo를 고른 이유:** 인증키가 필요 없고, 브라우저에서 바로 불러올 수 있으며(CORS 허용), 구름을 층별로 주고, 여러 좌표를 한 번에 조회할 수 있어서 서버 없는 GitHub Pages 사이트에 맞습니다. 비상업 무료 한도는 하루 10,000회입니다.

**기상청 자료를 바로 안 쓴 이유:** 동네예보(단기예보)의 하늘상태(SKY)는 맑음·구름많음·흐림 3단계뿐이라 구름 높이를 알 수 없습니다. 층별 구름이 있는 수치모델 자료(API허브)와 에어코리아는 인증키가 필요한데, 정적 사이트에 키를 넣으면 공개되므로 중간 서버가 있어야 합니다. Open-Meteo도 기상청 모델(KMA)을 제공하지만, 문서에 따르면 KIM 모델로 옮기는 동안 갱신이 멈춰 있어 기본 모델 묶음(best match)을 씁니다.

## 계산 방식

해 지는 방향으로 0·30·80·150·250·350·450 km 떨어진 7곳의, **해 진 뒤 10분** 시점 예보를 씁니다.

- **하늘 캔버스 C**: 0~250 km 중층 구름 + 0.8 × (중층 틈으로 보이는 상층 구름)의 가중 평균 U. 35~75%가 최고(1), 5% 아래는 0, 100%면 0.8.
- **햇빛 길 P** (광선 추적, 2026-11-04 개편): 캔버스 구름 밑면(중층 3.5 km, 상층 8 km)에서 해 쪽으로 빛줄기를 거꾸로 따라간다. 해가 지평선 아래 0~3°일 때 빛줄기 높이는 `h(x) = 구름 높이 − x·tan(해 각도) + x²/2R`. 하층(0.5~2.5 km), 중층(3.5~6.5 km), 상층(8~11 km) 띠 안을 지날 때마다 그 자리 구름량만큼 가리고(꽉 찬 띠 40 km에 하층 90%, 중층 70%, 상층 30% 가림), 땅에 닿으면 0. 맑은 하늘 값으로 나눠 지구 그림자 몫은 뺀다. 캔버스 구름 양으로 가중 평균.
- **지평선 G**: 150~350 km 구름 띠 중 빛을 못 받는 양만큼 지평선 노을을 깎음 (최대 60%).
- **머리 위 트임 S** = 1 − (0, 30 km 하층 구름), **서쪽 지평선 트임 Z** = 1 − (30, 80, 150 km 하층 구름).
- 점수 = (25·Z·(1−0.5·하층머리위)·G + 75·C·P·S·(0.5+0.5·Z)) × 공기(습도, 시정: 0.4~1) × 미세먼지(AOD: 0.7~1.05) × 비(0.35~1)

구름 없는 맑은 날은 지평선만 물드는 25점, 머리 위에 구름이 있고 해 쪽이 맑은 날은 80~90점대입니다. 구간: 0~19 나쁨, 20~39 보통, 40~59 좋음, 60~79 매우 좋음, 80~100 장관.

**왜 바꿨나 (2026-11-04):** 예전 공식은 해 쪽 먼 곳의 *낮은* 구름만 빛을 막는다고 봐서, 서해 위 350~450 km에 중층·상층 구름 띠(76~99%)가 있던 날을 83~88점으로 냈는데 실제 노을은 별로였다. 근처 공항 관측(평택 BKN170, 군산 BKN160)도 5 km 높이 중층 구름을 보여 줬다. 해가 1~3° 아래일 때 머리 위 구름에 닿는 빛은 서쪽 수백 km를 3~8 km 높이로 지나오므로, 그 높이의 먼 구름이 빛을 막는다. 새 공식으로 그날은 33점(보통)이다.

이 공식은 [Sunsethue](https://sunsethue.com/whitepaper)의 광선 방식 같은 공개 설명을 참고해 만든 **추정식**이고, 가중치는 대표 상황으로 맞춘 값이라 실제 노을 사진으로 맞춰 본 것은 아닙니다.
